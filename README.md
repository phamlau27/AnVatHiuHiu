## ✨ Tổng quan

**Ăn Vặt Híu Híu** là ứng dụng web bán hàng trực tuyến được thiết kế theo chuẩn **Mobile-First**, tối ưu trải nghiệm mua sắm nhanh gọn trên cả điện thoại và máy tính, tích hợp hệ thống quản trị đơn hàng và sản phẩm theo thời gian thực.

🌐 **Trải nghiệm trực tiếp:** [an-vat-hiu-hiu.vercel.app](https://an-vat-hiu-hiu.vercel.app)

---

## 🚀 Tính năng chính

* **Mua sắm & Tìm kiếm:** Duyệt sản phẩm theo danh mục, tìm kiếm nhanh theo từ khóa và sắp xếp theo nhu cầu.
* **Giỏ hàng & Đặt hàng:** Quản lý giỏ hàng linh hoạt, hỗ trợ giao hàng tận nơi hoặc nhận tại cửa hàng.
* **Theo dõi đơn hàng:** Cập nhật trạng thái đơn hàng theo thời gian thực, hỗ trợ chỉnh sửa hoặc hủy đơn.
* **Hệ thống quản trị (`/admin`):** Quản lý sản phẩm, theo dõi đơn hàng, thống kê doanh thu và nhận thông báo đơn mới qua Telegram.

## 🛠️ Công nghệ sử dụng

* **Frontend:** Next.js 16, React 19, TypeScript, Tailwind CSS, Framer Motion, Zustand
* **Backend & Database:** Firebase Firestore, Firebase Authentication, Next.js API Routes
* **Triển khai:** Vercel

## 💻 Cài đặt & Chạy dự án

```bash
# 1. Clone repository
git clone https://github.com/phamlau27/AnVatHiuHiu.git
cd AnVatHiuHiu

# 2. Cài đặt thư viện
npm install

# 3. Cấu hình biến môi trường
cp .env.example .env.local

# 4. Khởi chạy môi trường phát triển
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000) trên trình duyệt để xem ứng dụng.
